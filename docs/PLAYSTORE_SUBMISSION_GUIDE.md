# Google Play Console — Step-by-Step Submission Guide

## Prerequisites
1. **Google Play Developer Account** ($25 one-time registration fee).
2. **Production App Bundle (.aab)** or Trusted Web Activity (TWA) wrapper.
3. Completed store listing copy from playstore/STORE_LISTING.md.

---

## Submission Checklist

### Step 1: Create App in Play Console
- App Name: `Apex Equities: GSE & Stocks`
- Default Language: `English (United States)`
- App Type: `App`
- Free or Paid: `Free`
- Declarations: Accept Developer Program Policies and US Export Laws.

### Step 2: Set Up Store Listing
- Copy-paste the **Short Description** and **Full Description** from `playstore/STORE_LISTING.md`.
- Upload App Icon (512x512) and Feature Graphic (1024x500).
- Upload minimum 4 Phone Screenshots.

### Step 3: App Content & Policy Declarations
- **Privacy Policy:** Link to `https://meridian-equities.vercel.app/#privacy`
- **Ads:** Select `Yes, my app contains ads` (for the optional 2-Hour Pro Pass sponsor video) or `No`.
- **App Access:** Select `All functionality is available without special access` (Guest access is fully unlocked).
- **Financial Features:** Select `Stock market / financial information and portfolio tracking` (Declare that the app does NOT process retail banking deposits or execute regulated securities brokerage).
- **Target Audience:** Select `18 and over`.
- **Content Rating:** Complete the IARC Questionnaire (Rate as `Everyone / PEGI 3`).

### Step 4: Release & Rollout
- Upload the signed Android App Bundle (.aab).
- Enter the Release Notes from `playstore/RELEASE_NOTES.md`.
- Submit for review to the **Production Track**. Review typically takes 24–48 hours.
